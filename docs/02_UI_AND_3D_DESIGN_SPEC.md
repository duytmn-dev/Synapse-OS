# 02. ĐẶC TẢ GIAO DIỆN & VĂN PHÒNG 3D (Theo Design Reference)
Giao diện Dark Mode, 2 chế độ (`01 · Chỉ chat` và `02 · Chat + 3D`).

1. **Cột Trái (240px):**
   * Quản lý hội thoại & Bảng "Giới hạn" (Agent, % 5h, % Tuần) với thanh tiến trình ngang[cite: 2].
2. **Cột Giữa (Khung Chat):**
   * Hỗ trợ Tin nhắn, Khối Code tương tác (Copy, ▷ Run, </> Apply)[cite: 2].
   * Khối Media Preview: Video Player lớn bên trái, 2 Thumbnail nhỏ bên phải[cite: 2].
   * Smart Input Bar ở đáy có đính kèm file, chọn `@Agent` và nút `Mở 3D`[cite: 2].
3. **Cột Phải (3D & Task Tree):**
   * **Văn phòng 3D:** Góc Isometric. 5 phòng (QUẢN LÝ, CODEX, GEMINI Antigravity, CHATGPT, CLAUDE). Quan trọng: Trên đầu nhân vật 3D phải hiển thị huy hiệu Task ID (ví dụ: `(B1)`, `(B2)`)[cite: 2].
   * **Sơ đồ task:** Dạng cây phân cấp. Task cha `[B] Chọn khoảnh khắc` -> Sub-task con `[B1] Phát hiện cảnh`, `[B2] Chấm điểm cảnh`[cite: 2].
